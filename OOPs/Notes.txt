5. Instance Methods
-A method is a function defined inside a class.
-An instance method is a method that belongs to an object and can be called using that object.

Syntax:
class ClassName:
    def method_name(self):
        # statements
Example
class Student:
    def study(self):
        print("The student studies for 3 hour a day")

*Here, study() is an instance method.

*self
-self refers to the current object.
-It is written as the first parameter of an instance method.

Syntax:
def method_name(self):
    # statements
Example:
def study(self):
    print("The student studies for 3 hour a day")

#Calling an Instance Method
#We call an instance method using the object and dot . operator.

Syntax:
object_name.method_name()
Example
s1.study()

*We can call the same method using different objects:
s1.study()
s2.study()

#MUlTIPLE INHERITANCE (code oop11.py)
-Multiple Inheritance is a type of inheritance where one child class inherits properties and methods from two or more parent classes.

Eg:
class Parent1:
    pass

class Parent2:
    pass

class Child(Parent1, Parent2):
    pass

*Here class child can access the method of parent1 and parent2

#MULTILEVEL INHERITANCE (code oop12.py)
-Multilevel Inheritance is a type of inheritance where a class inherits from another class, and a third class inherits from that child class.

Eg:
class Parent:
    pass

class Child(Parent):
    pass

class GrandChild(Child):
    pass

#Here Grandchild can access method of child and parent ,child can access method of parent

#Polymorphism-method overriding
-Method Overriding occurs when a child class provides its own implementation of a method/use same method name in child class that already exists in the parent class.
eg:
class Parent:
    def method(self):
        pass

class Child(Parent):
    def method(self):
        pass

*if child class call method then the method of class will work
*or if we want the same feature to work as parent class in child class just code pass nad called method of parent using child object

#Abstract class(oop15.py)
-An Abstract Class is a class that is used as a blueprint for other classes.
 We cannot create an object directly from an abstract class.
-to create abstract class we need to import in new file
 *from abc import ABC, abstractmethod
 -we have to use decorator @abstractmethod
 -with the help of abrstract class it help to create the method with this method we cannot create an object or make sure to have
  this method

eg:
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def sound(self):
        pass

class Dog(Animal):
    def sound(self):
        print("Bark")

d = Dog()
d.sound()

*without sound method in Dog class we won't be able to create object
